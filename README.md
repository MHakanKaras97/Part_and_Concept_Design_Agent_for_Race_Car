# AI F1 Engineering Agent

An independent learning project: Claude plans a concept car part by part, Python validates every step, and
Autodesk Fusion builds and measures the geometry through its MCP server. Each part is kept in a versioned parts
registry (`data/`), and a local web UI drives the runs. The example included here is a concept-level "Mini F1"
assembly of 18 parts. A full README is coming in the next step.
